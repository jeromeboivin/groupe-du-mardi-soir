# Groupe du mardi soir

Song manifests and audio samples for the [Simple Looper](https://jeromeboivin.github.io/simple-looper/).

`songs/lovely-day/song.json` describes the pad samples, tempo, and playback chain.
Sample URLs are relative to the manifest, so the files can be served together
through GitHub Pages. The looper fetches the manifest when the song is loaded.
